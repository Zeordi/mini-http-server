# Mini HTTP Server Starter

Implement your HTTP/1.1 server here.

Expected binary name: `mini-http`
CLI: `./mini-http --port <port>` (default 8080)

Suggested layout:
- `src/` or `main.go` / `main.rs` / `main.c`
- `Makefile` / `Cargo.toml` / `go.mod`
- `public/` (already present: index.html, test.txt)

Serve static files from `./public` relative to your working directory.
